## 🚀 Что нужно сделать

### 1. Установить зависимости

```bash
npm install
```

Это установит:
- `bcrypt` - хеширование паролей
- `dotenv` - переменные окружения
- `mysql2` - драйвер MySQL
- `validator` - валидация данных

### 2. Настроить .env

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=ваш_пароль_здесь
DB_NAME=gtas_rp
DB_CONNECTION_LIMIT=10
```

### 3. Настроить базу данных

#### Для новой базы данных:
```bash
mysql -u root -p -e "CREATE DATABASE gtas_rp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p gtas_rp < database_schema.sql
```

#### Для существующей базы данных:
```bash
# ВАЖНО: Сделайте резервную копию!
mysqldump -u root -p gtas_rp > backup.sql

# Затем выполните миграцию
mysql -u root -p gtas_rp < database_migration.sql
```

⚠️ **ВНИМАНИЕ**: После миграции старые пароли НЕ БУДУТ РАБОТАТЬ! Пользователи должны зарегистрироваться заново.

### 4. Скопировать файлы в RAGE:MP

```bash
# Скопируйте в папку вашего RAGE:MP сервера
cp -r packages/* /путь/к/ragemp/packages/
cp -r client_packages/* /путь/к/ragemp/client_packages/
cp -r node_modules /путь/к/ragemp/
cp .env /путь/к/ragemp/
```

### 5. Запустить сервер

Запустите RAGE:MP сервер как обычно. В логах должно быть:

```
[Database] ✅ База данных gtas_rp подключена успешно!
[Inventory System] ✅ Система инвентаря загружена успешно!
[Admin System] ✅ Система администрирования загружена успешно!
[Server] ✅ Игровой режим загружен успешно!
[Transactions] ✅ Transaction system initialized
```

### 6. Создать первого администратора

1. Зарегистрируйтесь в игре
2. В MySQL выполните:
```sql
UPDATE users SET admin_level = 5 WHERE login = 'ВашЛогин';
```
3. Перезайдите в игру
